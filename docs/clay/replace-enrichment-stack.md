## How Waterfall Enrichment Actually Works

The concept is simple: for any data point you need (work email, company revenue, phone number), Clay tries multiple providers in sequence. If the first one doesn't have it, the second one tries. Then the third. And so on.

For example, finding a work email:

```
Provider 1: Clearbit    -> found? done. not found? try next.
Provider 2: Apollo      -> found? done. not found? try next.
Provider 3: Hunter      -> found? done. not found? try next.
Provider 4: Lusha       -> found? done. not found? try next.
Provider 5: RocketReach -> found? done. not found? try next.
Provider 6: Dropcontact -> found? done. not found? mark as missing.
```

You pay for one successful match, not six attempts. And your coverage rate jumps from whatever your single best provider delivers (usually 40-60%) to the combined coverage of all six (typically 80-95%).

This is why Anthropic went from ~30% to 90%+ enrichment. It's not that Clay has better data -- it's that Clay lets you use *everyone's* data in one waterfall.
