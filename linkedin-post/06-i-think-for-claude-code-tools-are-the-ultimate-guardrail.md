I think for Claude Code, tools are the ultimate guardrail.

The more I delegate tasks to AI, the more I feel the need for MCP or something similar that I can easily control at the tool level instead of the credential level. Most of the time it’s much easier to align a task to a tool than to a scope. Not to mention, many API providers don’t even offer fine-grained credential scopes.

Another thing I’ve found tools super useful for is their immutability. There have been so many times I’ve asked an agent to run a script to finish a job, and if for some random reason the script failed, instead of stopping and asking, the model just went ahead and modified the script. Sure, it may solve that one-time task, but it often causes more issues for the rest of the workflow.​​​​​​​​​​​​​​​​

In the context of Claude Code, tool immutability is the final guardrail that matters. Even hooks can be modified if you’re using shell scripts to implement them.
